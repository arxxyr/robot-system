## 2. Part 2 架构决策（已用户 AskUserQuestion confirm，详见 plan §"Architecture decisions"）

3. **watchdog 阈值 = `WatchdogConfig { heartbeat_timeout_ns }` 参数化**，默认 200 ms。测试用 50 ms。
4. **iceoryx2 baseline harness = 独立 binary**（`crates/robot-tests/src/bin/iceoryx2_rt_baseline.rs`），`--duration` CLI 参数。

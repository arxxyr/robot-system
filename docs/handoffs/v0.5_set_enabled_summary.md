## 2. 端到端链路（最终形态）

```
robotctl/client ──tonic──▶ gateway set_enabled handler（12 步：validate→auth→
  authz(operator+)→idempotency→deadline→build fbs→forward）
        │ 第 6 条 rr_io_thread（/<robot_id>/control/set_enabled）
        ▼
s0 set_enabled_rr_server（wire I/O only）──crossbeam──▶ ipc_thread
  §5.5b drain：deadline check → dry_run 评估（D7 read-only）/ live 单飞 +
    即时 precondition gate（LatchBlocked/GuardRejected 即拒；
    disable 且 state∈{Safe,Fault(_)} → 即时幂等 Disabled(Ok)，RS1）
    → push Event::Enable/Disable + PendingSetEnabled{target}
  §6.6b 每 tick resolve：EStop preempt > Stopping > Fault(AdapterErr)
    > target（EnabledActive/Safe）> deadline（D8 不回滚副作用）
        ▼
state machine：Enable=Safe→Ready（Pure）；heartbeat 驱动 Ready→Enabled.Active
  （Effectful Enable(true)）；Disable=Enabled→Safe（Effectful Enable(false)）
```

- **enable Ack ⟺ 观测到 Enabled.Active**（D8；非 Ready-accepted）——依赖
  heartbeat 源；无 heartbeat → 滞留 Ready → `DeadlineExceeded`（副作用不回滚，
  state 留 READY，e2e 实锁）。
- **disable Ack ⟺ Safe**（单 effectful，无 heartbeat 依赖）；Safe/Fault(_) 幂等
  即时 Ok（**不**清 Fault / latch，AC-3c）。
- `auto_enable=false`（resolved hardware 段，B2/B6）→ 启动留 Safe 等
  `SetEnabled(true)`；缺省 true 保既有无条件 auto-enable。

## 5. 非安全保证（延续 + 新增，必带）

- **C1 延续**：read RPC（GetState/StreamState）无 auth；`SetEnabled` 走 fake
  token 查表（v0.3 A1 模式），mTLS/OIDC 留 v0.5+。
- **D1**：单 S0 daemon 范围；多 daemon / whole-robot fanout 不在候选 C。
- **dry_run = precondition-only**（D7/B4）：`WouldAccept` **不**代表 adapter 会
  ack / enable 真完成；response 文案 "precondition would accept" 不写 "would
  succeed"。
- **幂等 Ok ≠ 清 Fault**（AC-3c）：Fault+disable 返 Ok 仅表"已非 enabled"；
  Fault 仍唯一由 `ClearError` 清，operator 经 `GetState` 另见。

## 7. 工程经验（接班 / 复用要点）

1. **多 tick pending 观测器读 state 不读 TickOutcome**：`ipc_tick` 的
   `TickOutcome` 只携 `clear_estop`（单 tick action）；SetEnabled 直接在
   post-tick 读 `state`（Enabled.Active/Safe/Fault(AdapterErr)），EStop preempt
   判据须在 ipc_tick drain events **前**抓（tick 后 queue 已空）。
2. **dry-run 与 live 共用同一 evaluator**：杜绝"dry-run 说能、live 走不同判断"
   漂移；RS1 的教训是 live 编排（pending target）也必须跟 no-op 幂等语义一致。
3. **e2e 状态观测器 = GetState**（候选 B read plane 复利）：s0 `pub_thread` 真发
   `s0_mode` → 跨进程断言 Safe/Ready/Enabled 无需任何测试后门。
4. **fake heartbeat 扮演 s1**（D-P3）：`/<robot_id>/s1/heartbeat` 50Hz 即可驱动
   Ready→Enabled.Active；不起 s1 让 e2e 拓扑省一个进程。
5. **release rebuild 必须先于 e2e gate**（RS2）：`locate_test_bin` 优先
   target/release；顺序错 = 拿旧二进制测新代码的假阴/假阳。
6. **count-bearing log 行别进 marker 全串**：readiness marker 用稳定前缀。

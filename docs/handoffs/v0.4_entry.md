### 1.3 v0.3 留下的对外契约（v0.4 必须保持向后兼容）

- **proto / fbs schema 仅 append**：B4 frozen `crates/robot-rpc/proto/robot_control.proto`
  + `crates/robot-msg/schemas/{action_request,action_status,action_event}.fbs`
  + 9 个 schema_id（0x0402-0x040A）。新 RPC / 新 ActionKind / 新 fbs body
  schema_id 走 append；不能改字段编号 / 不能 reuse deprecated id。
- **wire 契约 source_task_id 单调**（B3 §3.7）：S1 `TickState.cmd_seq`
  单一 source 驱动；gateway / s1 RR handler / events_drain **不**得在
  任一环节重写 `JointCommand.source_task_id` / `FrameHeader.seq`。
- **IdempotencyCache namespace key**（B4 §3.2）：`format!("{method}:{key}")`；
  4 个 `CachedResponse` variant 不强压同型。
- **Fingerprint 排除字段**（A1 + B4 沿用）：`request_id` / `timeout_ms` /
  `idempotency_key` 不进 fingerprint，避免合法 retry 误走 Conflict。
- **ActionRpcStatus → tonic::Code 显式 match**（A1 + B4 沿用）：禁止
  `as i32` cast；新 variant 让 length 对不上 → 单测失败强制更新。
- **shutdown 顺序契约**（B4 §3.5）：s1_daemon 必须按 `mark_shutting_down →
  rr.request_stop_all → rr.join_all → events_registry.stop_and_join_all`。
- **stream lifecycle**（B4 §3.6）：StreamTaskEvents 是 audit 通道；client
  drop stream **不**通知 s1。
- **rpc_roles.toml**：B4 (2/3-b) 收紧后 `[roles.operator]` 不持
  `clear_error`；ClearError = maintainer+。

### 3.2 候选 1 插值策略 = 线性插值 + waypoint dwell

理由（reviewer 拍板）：
- **不选直接跳点**：语义太弱（pose 切换瞬间无平滑）。
- **不选 cubic**：边界速度 / 加速度 / jerk 契约还没定义（等 v0.4 后期 /
  v0.5+ 配合 IK / trajectory backend 一起钉）。
- v0.4 ScriptedBackend 第一版只做**确定、可测、可解释**的 joint-space
  linear segment：`(target_pose, dwell_ms)` 序列，每段从 当前 pose →
  target_pose **per-joint 线性插值**，到 target 后 dwell `dwell_ms`，
  再进入下一段。

候选 1 land 时单独走 RIPER；本 entry **不**预钉死字段集 / lib API。

第一轮 round（trait 草案）：
- 范围：`robot-kinematics` trait 草案 + 错误模型；
  零 robot-s1 实现改动；零具体机器人实现。
- 交付：`crates/robot-kinematics/Cargo.toml` + `src/lib.rs` 含
  `ArmIkSolver` / `BaseKinematics` trait 定义 + `IkError` /
  `KinematicsError` enum + 单元测试（trait dyn-safety / 错误 variant
  穷举）。
- reviewer 拍板：trait 形态 / 错误模型 / dyn-safety / feature flag
  设计 / robot-s1 端 `Option<Box<dyn ArmIkSolver>>` 接入路径草案
  （不实现）。

第二轮 round（具体实现 + S1 wiring）：
- 范围：`robot-kinematics-xlerobot` impl + S1 持 trait + IkBackend +

- 节奏：沿 B2 / B3 / B4 同款 outline → reviewer round → (1/n) → ... →

```bash

  source ~/.cargo/env && \
  CARGO_BUILD_RUSTC_WRAPPER="" cargo clean'

ssh loosqk@10.0.1.41 'cd ~/repo/robot/robot-system && source ~/.cargo/env && \
  CARGO_BUILD_RUSTC_WRAPPER="" CARGO_HTTP_TIMEOUT=300 CARGO_NET_RETRY=10 \
```

## 5. 关键决策 / 文件改动总结

### 5.1 架构层

- **AdapterBuildContext 加字段**：`address: Option<&str>` + `motor_ids: &[u8]`
  （`docs/CHANGELOG.md` 2026-04-24 task 27b "字段扩展规则"已规定）
- **`Box<Inner>: ManipulatorAdapter` blanket impl** in `robot-core::adapter`：
  让 inventory factory 返回的 trait object 直接过 spawn_rt_thread<A> 泛型
- **by-id 优于 ttyACM**：udev 稳定路径，reboot / 拔插顺序变化不漂移；
  factory + config 全程透传任意 path 字符串
- **xlerobot-real feature**（robot-s0）：`xlerobot` + feetech `real-hw`，
  默认 features 仍 `xlerobot`（mock-only），dev / CI 不强制 libudev-dev

### 5.2 性能层

- **task 27c follow-up by-id hot path**：`FeetechAdapter::connect` 缓存
  `joint_ids: Vec<u8>` + 预分配 `pos_raw` / `vel_raw` / `cmd_entries` 缓冲
  → sync_read 13motor **-54%** (1044→482 ns)、sync_write 13motor **-54%**
  (298→138 ns)
- **rt_thread arc-swap thread_local warmup**（task 26 修复）：rt_thread init
  阶段一次性 `cmd_reader.load() / snapshot_pub.publish()`，让 arc-swap 在
  RT 线程的 hazard pointer slot 提前 alloc，主循环零 alloc

### 5.3 测试 / CI 层

- **CI matrix-build job**：3 combo（mock-only / xlerobot / atom01）
- **rt_guard_soak**：60s ignored 集成测试 + #[global_allocator] AllocDisabler
- **criterion bench**：5 组 17 case，hot path 数据入 verification.md 附录
- **flamegraph SVG baseline**：`docs/perf/2026-04-24_task27c_feetech_baseline/`
  含 sync_read 120s + sync_write 30s 火焰图 + 详细分析

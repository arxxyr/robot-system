## 4. reviewer 阻断闭环（3 轮）

### Round 1（A2-3 commit 04d14e1 之前 — 设计期 reviewer 4 条决策点）

reviewer 预先拍板 8 条硬边界（见 §3.A2-3）+ 提了 1 条非阻断 doc 残留

### Round 2（A2-3 commit 91bb8df — 真测试语义阻断）

`04d14e1` 后 reviewer 复核否决 2 条：

**阻断 1**：preflight `systemctl --user is-system-running` 只看 exit
code 是否存在，没真识别 user manager 不可用。`Failed to connect to
bus` / `No such file` 等环境错被放进 iteration → 走 exit 2 FAIL，违反
"preflight / 环境错 exit 1，**不**算测试失败" 拍板。

**阻断 2**：重启后没确认新 daemon active / Ready。
- `read_active_pid()` 拿到非 0 PID 不等于 `Type=notify` 第二次 READY 完成。
- journal markers `freeze_control thread ready` + `watchdog ping started`
  统计；后者源码里**没有**这个 log，实质只数前者。前者发生在
  `systemd_notify::ready()` 之前，**不**能替代"新 daemon active"。

**修复**（commit `91bb8df`）：
- preflight 改 `Command::output()` 捕获 stdout + stderr；stderr 匹配
  "Failed to connect to bus" 等 + stdout 第一 token 必须 ∈
  `[running|degraded|starting|initializing]`。
- 重启验证加 `wait_for_active_pid_distinct_from(unit, pid0, timeout)`：
  100ms 轮询 read MainPID + `is-active` 二次确认 + 强制 `pid != pid0`。
- journal 拆 4 条独立硬断言：`withholding sd_notify ≥ 1` /
  `s0_daemon starting ≥ 2` / `freeze_control thread ready ≥ 2` /
  `state=Ready ≥ 1`。删假断言 `watchdog ping started`。

reviewer round 3 复核：放行 push + 进 A2-4 Orin。

### Round 3（A2-4 Orin 复跑暴露 — journal query 跨发行版兼容）

`91bb8df` 在本机 (FRIDAY) 5/5 PASS，但 Orin AGX 1 round 跑 FAIL：

**现象**：
```
✓ daemon active, PID0=1126706
✓ published freeze cmd: worker=Ipc duration_ms=5000
✓ PID switched: PID0=1126706 → PID1=1126718 (is-active confirmed)
✗ FAIL: journal hard-asserts FAIL (4 条):
  - missing 'withholding sd_notify' warn; count=0
  - 's0_daemon starting' count=0 (期望 ≥ 2)
  - 'freeze_control thread ready' count=0 (期望 ≥ 2)
  - 'state=Ready' / '"state":"Ready"' count=0 (期望 ≥ 1)
journal tail: -- No entries --
```

**诊断**：daemon 行为本身**全对**（PID 切换 + is-active confirmed）；
手动跑 `journalctl _SYSTEMD_USER_UNIT=<unit>` 输出**完整**，含
`freeze_control: applied` / `withholding sd_notify(WATCHDOG=1)` / 第二
次 `s0_daemon starting` / `state=Ready` 全部硬断言所需字串。但 smoke 用
`journalctl --user -u <unit>` 返 `No journal files were found.`

**根因**：Ubuntu Tegra (Orin AGX) **未启用** user journal namespace
（`/var/log/journal/<user>/` 不存在）；user services 的 stdout/stderr 仍
路由到 system journal，但带 `_SYSTEMD_USER_UNIT=<unit>` 索引。`--user`
视角看不到。FRIDAY workstation 启用了 user journal 所以 `--user -u` 工作。

**修复**（commit `b33b5c4`）：smoke `journalctl_user` 改成
`journalctl _SYSTEMD_USER_UNIT=<unit>` matcher，跨 user-journal 启用 /
不启用配置稳。本机 FRIDAY 5/5 重跑无回归 + Orin 1 round 重跑 PASS。

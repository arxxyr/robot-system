## 2. 7 子命令契约（operator CLI）

| 子命令 | RPC | exit 语义 | 权限（服务端真 enforce?）|
|---|---|---|---|
| `clear-estop` | ClearEStop | 四道闸早拒 exit 2（token→confirmation→audit-reason 顺序短路）；server PermissionDenied exit 3；Ok exit 0 | maintainer+（写 RPC，CommandMeta 真 authz）|
| `clear-error` | ClearError | token+audit gate exit 2；Ack 输出 | maintainer+（真 authz）|
| `get-task-status <id>` | GetTaskStatus | action-id UUIDv7 校验 exit 2；NotFound exit 4；三态输出 | **client-side token gate only**（read RPC，TaskHandleRef 无 auth，服务端 v0.3 unauthenticated；详 §P.4 C1）|
| `cancel-task <id>` | CancelTask | action-id + token+audit；Ack（无 dry_run）| operator+（写 RPC 真 authz）|
| `stream-events <id>` | StreamTaskEvents | 每帧一行；终态 exit 0；SIGINT exit 0 + warning；整流 --timeout-ms exit 6 | **client-side token gate only**（同 get-task-status；§P.4 C1）|
| `invoke scripted` | InvokeTask kind=Scripted | --waypoints-file JSON + ragged 检查 exit 2；action_id 输出；--follow | operator+（写 RPC 真 authz）|
| `invoke ik` | InvokeTask kind=Ik | --target-x/y/z f64；quat 默认 0001 透传；action_id；--follow | operator+（真 authz）|

**统一**：`tonic::Code → exit code` exhaustive 映射（AC-5：3 auth / 4 业务 /
5 connect / 6 deadline / 7-10 保留）；`CommandMeta` 构造（request_id UUIDv7 /
idempotency `cli-<request_id>` 自动 + info 行 / source `cli.<USER>`）；`--json`
schema 化输出；连接失败 exit 5；client deadline 由 `complete_ack_rpc` 的
`tokio::time::timeout` 独占 exit 6（不靠 endpoint timeout 不稳定 code）。

## 3. §P.4 Plan-Execute diff 汇总（A1-E5；**审计必读**）

详见 [`team-swe/specs/v0_5_operator_cli.md`](../../team-swe/specs/v0_5_operator_cli.md)

- **A4（必带）**：robot-cli 无条件依赖 `robot-rpc/client` → workspace feature
  unification → `cargo test --workspace` **默认跑 `task_rpc_e2e` 6 cross-process**

- **C1（⚠ 非安全保证）**：`get-task-status` / `stream-events` 的 token gate 是
  **CLI 本地策略 gate**（缺 token exit 2），但 **token 不上 wire**（`TaskHandleRef`
  无 auth 字段，v0.3 read RPC 服务端 unauthenticated）。**不得**据此认为 read RPC
  已 viewer+ 鉴权；服务端 read auth 留 v0.5+ metadata 路径。

  带 dry_run + S0 action layer 真识别）；其余 6 子命令 wire fbs 不带 dry_run →
  CLI 一律 exit 2 拒（防"flag 接受但实发真实动作"危险误导）。新增 gateway 子命令
  **默认拒 --dry-run**，除非其 wire fbs 真带 dry_run。

## 5. robotctl_smoke 工程经验（接班 / 复用要点）

- **审查重点 3 结构化**：robotctl_smoke **只** `dep:tokio + serde_json`，**不**引
  robot-rpc/tonic —— "smoke 不调 tonic client" 从纪律变成编译期边界（物理上无法
  import `RobotControlClient`）。唯一被测路径 = `tokio::process::Command` spawn
  `robotctl` + 读 stdout/exit。
  〔**2026-08-27 Reverse Sync**（候选 E 段(8) round 2，`v0_5_dimos_replace.md` PX-19）：段(4) 起 robotctl_smoke 用 `robot_rpc::client::layout`，"不引 robot-rpc" 已破；边界改述为"不启用 `robot-rpc/client`、不调 tonic client"，feature 表 `robotctl-smoke += dep:robot-rpc`（不开 client、不拉 tonic）〕
- **readiness 不走 tonic**：TCP connect + s1 stderr marker `rr_server_threads
  ready` + `robotctl get-task-status <NEVER_ACTION_ID>` 直到 exit 4（NotFound）
  探针（全链就绪）。
- **status 单发 latest() 竞态**（重要）：`robotctl status` 单次读 latest() 受
  iceoryx2 late-subscriber 投递时机影响（投递在订阅者连接后下一次 publish；status
  立即读 → 通常 "no sample yet"）。**这是单发读的固有竞态，非 robotctl bug**。
  故 AC-2 status/watch deterministic byte-diff **主证走 `watch`**（persistent
  subscriber 循环 reliable 读 fixed sample → sample-block byte-identical + 含
  layout）；status 只断言 exit 0 + 跨运行 byte-identical（与 watch 共用同一
  `print_snapshot` 渲染路径，robotctl.rs:425）。
- **fixed-stamp FakeStatePublisher**：regression phase 用固定 stamp + 固定
  positions 让 status/watch 输出 deterministic（无自生 clock）；happy phase 用
  fresh stamp（s1 anchor 需 fresh）。
- **不可达 gateway 作早拒证据**：safety violations / dry-run matrix 用
  `127.0.0.1:1` → 早拒必须 exit 2 ≠ connect-fail 5（证未发 RPC）。
- **SIGINT readiness gate**：流式 spawn → 读首 `event=` 帧 → `libc::kill(pid,
  SIGINT)` → 有界等 exit 0 + warning。不靠固定 sleep 赌时序。

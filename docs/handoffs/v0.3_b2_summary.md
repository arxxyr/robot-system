## 1. 范围 / 不在范围

### 1.1 在范围（已 land）

- `crates/robot-s1/src/action.rs`：B2 lib 类型骨架
  （[`ActionId`] / [`ActionKind`] / [`ActionRequest`] / [`ActionBackend`] /
  [`ActionInstance`] / [`JointCommandBody`] / [`ActionTicket`] /
  [`ActionEvent`] / [`ActionStatus`] / 错误枚举包括
  `SubmitError::NotReady` + `SubmitError::BackendStartFailed`）。
- `crates/robot-s1/src/action_backend/`：backend 静态注册基础设施
  （[`BackendRegistry`]：`from_inventory` / `from_explicit` / `dispatch`）+
  唯一 backend 实现 [`MockDwellBackend`]（feature `backend-mock-dwell`
  gate；默认 on）。
- `crates/robot-s1/src/coordinator.rs`：5-state 机（`Booting` / `Idle` /
  `Executing` / `Degraded` / `ShuttingDown`）+ [`Coordinator`] struct
  （`new` / `mark_idle` / `mark_shutting_down` / `submit` / `cancel` /
  `status` / `clear_error` / `current_state` / `tick_action` / 3 个
  accessor）+ [`ProfileSection`] L1 parse + L2 validate（unknown
  backend / unsupported command mode / joint count mismatch / no
  enabled backends）+ [`run_action_tick_loop`] state-aware tick
  dispatch。
- `crates/robot-s1/src/bin/s1_daemon.rs`：B2 (3/3) wiring —— parse
  `[s1.profile]` → `BackendRegistry::from_inventory` → `validate_profile_section`
  → `Coordinator::new` + `mark_idle` → `run_action_tick_loop`。退出
  时 `mark_shutting_down` 让 ticket 持票方收 `RecvError`。
- `crates/robot-s1/tests/action_dispatch.rs`：8 路径 in-process
  integration test，覆盖 reviewer 验收契约 5 路径 + override Some/None
  二分 + 阻断 2 NoEnabledBackends + B1 baseline regression。

### 1.2 不在范围（→ B3 / B4 / 其它）

- **B3** 真 backend：IK solver / RL policy / scripted controller 闭
  环。落地对应 backend 时扩 `ActionKind` enum（向 `docs/00_design.md`
  §6.6.4 errata 边界对齐）。
- **B4** robot-rpc full gateway：`tonic` codegen + `InvokeTask` /
  `CancelTask` / `GetTaskStatus` / `StreamTaskEvents` / `ClearError`
  RPC + sync↔async adapter thread 把 `std::sync::mpsc::Receiver` 桥
  到 `tokio::sync` —— B2 lib 已埋好接口（`ActionTicket.events:
  std::sync::mpsc::Receiver<ActionEvent>`），B4 只需补 transport。
- **HOMING 状态实现**：B2 跟 B1 一致跳过；启动锚定 = anchor read +
  立即 mark_idle。
- **`sd_notify` watchdog**：B1 决策 #7 锁定 `Type=simple`；B2 不触。

### 3.4 B2 (2/3) 拍板补充（实现期发现）

- `SubmitError::NotReady`（reviewer 拍板）：`Booting` 状态拒 submit
  用 `NotReady`，**不**复用 `ShuttingDown`（两阶段生命周期相反）；
  Display 文案 reviewer 给定 `coordinator is not ready; startup
  anchor has not completed`。落地 89628b9。
- `SubmitError::BackendStartFailed(ActionStartError)`（B2 (2/3) 落地
  报告 reviewer ACK）：dispatch 通过、状态可接受时 `backend.start()`
  自身可返 `ActionStartError`；纯加 variant 桥接 `submit` 返回类型。
  落地 89628b9。

### 3.5 B2 (3/3) 评审口径（落地报告 + ACK）

- "EXECUTING 期间 cmd_ch 不递增" 必须**二分**：
  - MockDwell None 窗口：cmd_ch 不递增 = override 阻塞 hold loop。
  - 自产 Some(body) backend：cmd_ch 递增 = action command 仍能 publish。
  落地 `tests/action_dispatch.rs` `happy_a` + `happy_b` 两条互证测试。
- visibility 升级（`pub(crate) → pub`）：integration test crate 仅看
  lib pub 表面；B1 precedent (`run_tick_loop` / `read_anchor_from_s0_state`)
  支持升级。落地 96fb757 doc 段说明。

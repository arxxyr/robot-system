**新核心 `run_robotctl`（审查重点 3 唯一被测路径）**：

```rust
struct RobotctlOutcome { code: i32, stdout: String, stderr: String }

async fn run_robotctl(bin_dir, gateway_addr, token: Option<&str>, args: &[&str])
    -> Result<RobotctlOutcome, String>
{
    let mut cmd = tokio::process::Command::new(bin_dir.join("robotctl"));
    cmd.args(args);
    cmd.arg("--gateway-addr").arg(gateway_addr);
    cmd.env("NO_COLOR", "1").env_remove("ROBOT_GATEWAY_ADDR");
    match token { Some(t) => { cmd.env("ROBOT_TOKEN", t); }, None => { cmd.env_remove("ROBOT_TOKEN"); } }
    cmd.stdout(Stdio::piped()).stderr(Stdio::piped());
    let out = cmd.output().await.map_err(...)?;
    Ok(RobotctlOutcome { code: out.status.code().unwrap_or(-1), stdout: ..., stderr: ... })
}
```

`stream_events_sigint` 用**流式** spawn（不 `output()`）：spawn → `BufReader`
stdout `.lines()` 读到首个含 `event=` 的行（readiness gate）→ `libc::kill(pid,
SIGINT)` → 有界 `child.wait()` → 验 exit 0 + stderr 含
`warning: stream interrupted before terminal event`。

### 3.2 `executor.execute_step()` 实际下发路径

```python
# src/xlerobot_dimos/policy/executor.py:73-119
def execute_step(client: Any, positions: dict[str, float], dt_s: float = 0.1) -> None:
    # (1) 读当前关节
    current = client.get_joint_positions()

    # (2) 构 trajectory + 下发 2 个 task（左/右臂 traj_left_arm / traj_right_arm）
    for task_name, joint_names in {"traj_left_arm": LEFT_ARM_JOINTS,
                                    "traj_right_arm": RIGHT_ARM_JOINTS}.items():
        target = [positions.get(j, current.get(j, 0.0)) for j in joint_names]
        start  = [current.get(j, 0.0) for j in joint_names]
        traj = JointTrajectory(
            joint_names=joint_names,
            points=[
                TrajectoryPoint(positions=start,  time_from_start=0.0),
                TrajectoryPoint(positions=target, time_from_start=dt_s),
            ],
        )
        client.task_invoke(task_name, "execute", {"trajectory": traj})

    # (3) Gripper：单独下发（biso101 action 里是 absolute normalized）
    for hw_id, joint_name in {"bus1": "left_arm_gripper",
                               "bus2_arm": "right_arm_gripper"}.items():
        if joint_name in positions:
            client.set_gripper_position(hw_id, float(positions[joint_name]))
```

**dimos 内置 RPC 用了 3 个不同接口**：

| dimos RPC | 用途 | robot-system 对等 |
|---|---|---|
| `client.get_joint_positions()` | 读当前关节（用作 trajectory start point） | **❌ 缺**（v0.5+ 待 land `GetState` / `StreamState`）|
| `client.task_invoke(task_name, "execute", {"trajectory": traj})` | 下发 trajectory；按 task_name 路由（traj_left_arm / traj_right_arm 等）| 🟡 `InvokeTask(kind=Scripted, payload=ScriptedPayload)` 候选 1 已 land —— **但** payload 字段不 1:1 对等（dimos `JointTrajectory(joint_names, points=[{positions, time_from_start}])` vs robot-system `ScriptedPayload(waypoints=[{positions, dwell_ms, segment_duration_ms}])`；wire 需要 adapter） |
| `client.set_gripper_position(hw_id, val)` | 下发夹爪 absolute normalized | **❌ 缺**（v0.5+ 待拍板 gripper RPC 入口；或扩 `InvokeTask` 把 gripper 当 joint 一起下发）|

**结论**：

- 3 个 RPC 里 1 个能改造（`task_invoke` → `InvokeTask + Scripted`），
  2 个**完全缺**（GetState / Gripper）
- 即使候选 4 现在开实施，至少要等 v0.5+ land `GetState` + `Set
  Gripper` 之后才能让 `executor.execute_step()` 完整跑通
- 单切第二个 RPC（`task_invoke`）需要双仓协调，但前一步 `get_joint_
  positions()` 都没东西可对接，integration 不可能闭环

## 4. 缺口表（v0.5+ 阻塞项）

按 dimos-deploy 实际调用面盘 robot-system 端缺口：

| dimos-deploy 调用点 | 当前依赖 | robot-system 替换需要 | robot-system 状态 |
|---|---|---|---|
| `executor.execute_step()` 第 (1) 步读状态 | `client.get_joint_positions()` | `GetState` 单调用 或 `StreamState` server-streaming | ❌ 未 land（v0.5+）|
| `executor.execute_step()` 第 (2) 步下发 trajectory | `client.task_invoke(task_name, "execute", {trajectory})` | `InvokeTask(kind=Scripted, payload=ScriptedPayload)` + dimos-deploy 端 `JointTrajectory → ScriptedPayload` adapter | 🟡 robot-system 端就绪；dimos-deploy 端 0 行 wrapper |
| `executor.execute_step()` 第 (3) 步下发 gripper | `client.set_gripper_position(hw_id, val)` | 待拍板 gripper RPC 入口（不在 robot-system 当前 6 RPC）| ❌ 未 land |
| `coordinator_xlerobot_full.py` 启动期 `auto_enable=True` | dimos 框架自动 | `SetEnabled` RPC（启动期或运行期）| ❌ 未 land（v0.5+）|
| dimos-deploy 当前**未触发** EStop | 无 | `EStop` 触发 RPC + operator workflow | ❌ 触发 RPC 未 land；ClearEStop 已 land |
| `web/server.py` cartesian endpoint | `ArmIK(side).solve(...)` 本地 import | `InvokeTask(kind=Ik, payload=IkPayload)` + dimos-deploy 端 wrapper | 🟡 robot-system 端就绪；dimos-deploy 端 0 行 wrapper；ROI 低 |
| `coordinator_xlerobot_full.py` 当前 LCM transport（`joint_state` / `cmd_vel`）| dimos LCMTransport | iceoryx2 zero-copy channels 或新 RPC | ❌ 跨架构切换；超过 6 RPC scope |

## 5. Python gRPC stub 生成方式（不展开选型）

按 reviewer 拍板"不要再扩到 Python protobuf 选型细节，外部 gRPC 已
经不急"，本节仅记**存在哪些路径**作未来 v0.5+ 触发后的参考：

- proto 源 = `crates/robot-rpc/proto/robot_control.proto`（单文件；
  6 RPC）
- 可选生成路径 3 类：`grpcio-tools` 官方 protoc plugin / `betterproto`
  asyncio-friendly / `buf generate` 多 client 语言
- 维护责任 3 类：robot-system 仓库 own（发 PyPI）/ dimos-deploy 仓
  库 own（每次同步跑 gen）/ CI 双端联动
- **任一选型都需要先有 dimos-deploy 端 buy-in + 测试入口 + 跨仓
  PR 流程，单边定不下来**

**defer 理由**（reviewer 拍板锁定）：

1. 没有 call site 就没法 own 选型 —— 即使现在选了 `grpcio-tools`，
   dimos-deploy 端没有 wrapper，stub 跑不起来；
2. 一旦发 PyPI 包，外部接口承诺锁定 + 维护负担长期化；现在 6 RPC
   schema 还在演化（`StreamTaskEvents` 是 per-ActionId pubsub
   bridge，不是纯 server-streaming，Python client 行为还要单独
   设计），不适合此时锁版本。

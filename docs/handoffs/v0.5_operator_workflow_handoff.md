## 1. Q1 — 10 RPC × operator/maintainer/admin 工作流怎么串

### 1.1 授权模型：**显式 capability 列表，非层级**

`auth.rs` 的授权决策是 `role_has_capability(role, cap)` = `caps.contains(&cap)`
（`auth.rs:126`）——**逐 role 显式列 capability，不是数值比较**。`Role` enum 虽
`Ord` 升序（Viewer<Operator<Maintainer<Admin，`auth.rs:26`）但**仅 audit
cross-check 用，授权不走 `>=`**。

> ⚠ **"operator+" 的真实含义**：某 capability 必须在 `configs/rpc_roles.toml`
> 的 **operator、maintainer、admin 三个 role 下都显式列出**才成立。漏列任一个 =
> 该 role 被拒。改 toml 时务必三处同步（生产表 `rpc_roles.toml` 已对齐；
> `auth.rs` 单测 fixture `VALID_TOML` 是**子集**，maintainer/admin 未列
> set_enabled/estop，**仅** unit 用、与生产无关）。

授权决策**全在 gateway**（robot-rpc::auth）；wire `RpcRole` 字段仅 audit，**daemon
不做授权**（`auth.rs:5-6`）。token = **fake token 查表**（`rpc_roles.toml [tokens]`），
**非**加密/签名校验；mTLS/OIDC 推 v0.5+（见 §2 非安全保证）。

### 1.2 10 RPC × role 访问矩阵（生产 `rpc_roles.toml` 实测）

| RPC | capability | viewer | operator | maintainer | admin | wire auth 字段 |
|---|---|:--:|:--:|:--:|:--:|---|
| `GetState` | `read_state` | ✓ | ✓ | ✓ | ✓ | **无**（`GetStateRequest{hardware_id}`，不读不校验 token）|
| `StreamState` | `read_state` | ✓ | ✓ | ✓ | ✓ | **无**（`StreamRequest`）|
| `GetTaskStatus` | `read_state` | ✓ | ✓ | ✓ | ✓ | **无**（`TaskHandleRef`，无 `CommandMeta`）|
| `StreamTaskEvents` | `read_state` | ✓ | ✓ | ✓ | ✓ | **无**（`TaskHandleRef`）|
| `InvokeTask` | `invoke_task` | ✗ | ✓ | ✓ | ✓ | `CommandMeta.auth.token` |
| `CancelTask` | `invoke_task` | ✗ | ✓ | ✓ | ✓ | token |
| `SetEnabled` | `set_enabled` | ✗ | ✓ | ✓ | ✓ | token |
| `EStop` | `estop` | ✗ | ✓ | ✓ | ✓ | token |
| `ClearError` | `clear_error` | ✗ | ✗ | ✓ | ✓ | token |
| `ClearEStop` | `clear_estop` | ✗ | ✗ | ✓ | ✓ | token |

分级归纳：**viewer+**（4 条只读）/ **operator+**（InvokeTask·CancelTask·SetEnabled·
EStop）/ **maintainer+**（ClearError·ClearEStop）。

**两条硬不变量**（改 toml 会被回归锁测拦）：
- `clear_estop` **必须 maintainer+**（`auth.rs::check_clear_estop_invariant`
  load 期自检 + `repo_rpc_roles_toml_passes_invariants` 锁生产表；放宽 = §6.7 #3 阻断）。
- `clear_error` **收紧到 maintainer+**（B4 (2/3-b)；operator 删，错误恢复 = maintainer+）。

### 1.3 工作流怎么串（典型 operator session）

```
viewer      ── GetState / StreamState ───────────▶ 监控 mode/safety_state/fault_code
            ── GetTaskStatus / StreamTaskEvents ─▶ tail 任务终态 / 审计流
operator    ── SetEnabled(true) ─────────────────▶ Safe→Ready→Enabled.Active（依赖 s1 心跳）
            ── InvokeTask(kind, payload) ────────▶ 返 TaskHandle{action_id}
            ── (GetTaskStatus/StreamTaskEvents 用 action_id 跟踪)
            ── CancelTask(action_id) ────────────▶ cooperative 取消（终态走事件流）
            ── EStop(reason) ────────────────────▶ publish→S0 latch SAFE（紧急，operator 也能按）
            ── SetEnabled(false) ────────────────▶ →Safe（torque-off）
maintainer  ── ClearError ───────────────────────▶ 清 coordinator Degraded（内存，非 latch）
            ── ClearEStop(confirmation) ─────────▶ 清磁盘 estop_latch（唯一解锁路径）
admin       ── (= maintainer 全集 + set_policy/shutdown，本 proto 暂未上线后两条)
```

关键串接点：
- `InvokeTask` 返 `TaskHandle.action_id`（UUIDv7 hex）→ 后续 `GetTaskStatus` /
  `CancelTask` / `StreamTaskEvents` 用同一 `action_id`。`meta.request_id` = `ActionId`
  源（gateway 不翻译）。
- **触发 EStop = operator+；解锁 ClearEStop = maintainer+**（分权：谁都能急停，
  解锁需更高权限 + `confirmation` 非空串）。
- enable 是**两段**：`SetEnabled(true)` Ack ⟺ 观测到 `Enabled.Active`，**依赖 s1
  心跳源**；无心跳 → 滞留 Ready → `DeadlineExceeded`（副作用不回滚，见 §2）。

## 2. Q2 — 哪些错误码 / 非安全保证必须暴露给 dimos-deploy 接班方

### 2.1 tonic `Status::code` 错误码契约（client 必须分类处理）

| tonic Code | 触发 | client 应对 |
|---|---|---|
| `InvalidArgument` | meta 缺失 / `request_id` 非 UUIDv7 / 空 `idempotency_key` / `timeout_ms=0` / 空 `hardware_id` / **EStop `dry_run=true`**（D4，无可评估物）| 修请求，**不**重试原样 |
| `Unauthenticated` | token 缺失 / 查表无此 token | 配置 token（fake token，见 2.3）|
| `PermissionDenied` | role 无该 capability（如 operator 调 ClearEStop）| 换更高权限 token；**不**重试 |
| `FailedPrecondition` | 写 RPC 前置不满足（如 InvokeTask 的 PayloadDecode/HardwareMismatch/Rejected；SetEnabled latch/guard 拒）| 读 `GetState` 看态，纠正后再发 |
| `NotFound` | `hardware_id` 不在 gateway `--config` 声明池（**禁 fallback**）| 修 hardware_id |
| `Unavailable` | 已知 hardware 但常驻池**无首帧** / rr_io 线程已停 / **gateway 正在 shutdown** / estop_pub Disconnected | 退避重试（瞬态）|
| `ResourceExhausted` | idempotency cache 满 / forward channel 满（`bounded`，背压）| 退避重试 |
| `DeadlineExceeded` | gateway 侧等 RR/publish 超时 / SetEnabled 未在 deadline 内到 Enabled.Active | ⚠ **副作用可能已发生**，见 2.2 |
| `AlreadyExists` | 同 `idempotency_key` **不同 payload**（Conflict）| bug：同 key 必须同 payload |
| `Internal` | estop_pub loan/publish Err / fbs decode 失败 / daemon adapter 执行失败（RpcStatus::Internal）| 报警 + 人工 |
| `Ok` | 成功；`Ack.cleared_at_ns` 语义见 2.2 | — |

daemon→gateway 的 fbs `RpcStatus` 域（`clear_estop.fbs`，A1 锁，ClearEStop/SetEnabled
复用）= `Unknown/Ok/FailedPrecondition/PermissionDenied/InvalidArgument/Internal/
DeadlineExceeded/ResourceExhausted/Aborted`，gateway `rpc_status_to_tonic_code` 转
上表 tonic Code（`gateway.rs:736/1037` 单源 mapper）。

### 2.2 弱语义 / 幂等（dimos-deploy 必须理解，否则会误判）

- **幂等键**：同 `idempotency_key` + 同 payload → **replay** 缓存的 Ack（不重复副作
  用）；同 key + 异 payload → `AlreadyExists`。`request_id`（每次重试变，audit）**≠**
  `idempotency_key`（跨重试稳定）。
- **`DeadlineExceeded` 不等于"没发生"**：gateway 过早超时可能"副作用已发生但
  client 以为失败"。重试前先 `GetState` 核实态。
- **EStop 弱 Ack（D2，proto:123-129 明文）**：`Ack.cleared_at_ns = published_at_ns`
  （publish 成功时刻）。**不**证 S0 已消费、**不**证 latch 已 fsync（pub/sub 无回执；
  `RobotState` 无 `estop_latched` 字段 → latch fsync **远程不可观测**）。**S0 不在时
  EStop RPC 仍 Ack** —— **EStop RPC 不是 S0 死亡场景的救命索**，该场景靠硬件
  fail-safe 兜底（§6.7 #1）。远程可观测面 = `GetState` 运行态（`mode=SAFE` +
  `safety_state`）。
- **SetEnabled enable Ack ⟺ `Enabled.Active`**（依赖 s1 心跳；无心跳 →
  `DeadlineExceeded`，副作用不回滚、留 Ready）；disable Ack ⟺ Safe（无心跳依赖）。

### 2.3 非安全保证（**必须**写进 dimos-deploy 接班契约）

- **认证 = fake token 查表**（`rpc_roles.toml [tokens]`），**非**加密/签名；**仅** dev/
  staging；生产部署**必须**换真 token store。mTLS/OIDC 推 v0.5+。
- **gateway loopback-only bind + plain TCP**（不暴露外网；TLS/mTLS 留 v0.4+）。
  dimos-deploy 若远程调用，需自带安全隧道。
- **4 条只读 RPC 服务端不认证**（C1）：`GetState`/`StreamState`/`GetTaskStatus`/
  `StreamTaskEvents` 的 request **无 auth 字段**，gateway **不读不校验 token**
  （`gateway.rs:1409/1446`）。读侧 token gate 只在 client（如 robotctl）侧、**不上
  wire**。dimos-deploy 不能假设"读 RPC 有服务端鉴权"。
- **写 RPC token-gated 但 token 非密**：role 决策在 gateway，wire `RpcRole` 仅 audit。
- **`dry_run` 进 daemon action layer 真评估**（ClearEStop/SetEnabled；gateway 不短
  路）；**EStop 不支持 dry_run**（`dry_run=true` → InvalidArgument）。
- **`StreamTaskEvents` 非纯 server-streaming**：底层是 per-ActionId pubsub bridge，
  终态（COMPLETED/FAILED/CANCELLED）后流关闭，单 ticket 至多 1 条终态；Python
  client 行为需单独设计（见 §3）。
- **robotctl 直连 `estop` 旁路**（`source="robotctl"`/`latched=true`）是**既有语义
  债**，与 gateway RPC 路由（`source="rpc"`/`latched=false`）不同；dimos-deploy 走
  **gateway RPC**，不碰直连旁路（债务详 CHANGELOG 2026-06-24）。

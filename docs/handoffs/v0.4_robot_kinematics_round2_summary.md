**IK 内部 joint 限位**（用于 `_planar_ik` 内部 clamp `joint_shoulder`
/ `joint_elbow` 变换前的角度），**不是** motor 角度限位。

round 2 实施期初稿误判这是 motor 角度限位 → `solve_respects_joint_
limits` lib unit 失败；改用：
- `IK_INTERNAL_SHOULDER_LIMIT` / `IK_INTERNAL_ELBOW_LIMIT`（用于
  `_planar_ik` 内部 clamp `joint_shoulder` / `joint_elbow`）
- `SHOULDER_LIFT_LIMIT = [π/2 - 3.37, π/2 + 0.22]` / `ELBOW_FLEX_
  LIMIT = [-π/2 + ..., -π/2 + ...]`（motor 角度限位，从坐标变换
  `π/2 - joint_shoulder` / `joint_elbow - π/2` 推导；
  `KinematicInfo::joint_limits` 暴露）

`KinematicInfo.joint_limits` 顺序对齐 5-DOF joint 顺序：
`[SHOULDER_PAN_LIMIT, SHOULDER_LIFT_LIMIT, ELBOW_FLEX_LIMIT, WRIST_
FLEX_LIMIT, WRIST_ROLL_LIMIT]`。

### 5.4 FK round-trip 容差

`solve_round_trip_via_fk_within_1cm` lib unit：solver target → solve
→ `planar_fk(shoulder_lift, elbow_flex)` → 比对水平距离 + z；容差
`1e-2` m（1 cm）。

容差较松的原因：dimos `arm_ik.py` 的连杆偏移补偿（`THETA1_OFFSET` /
`THETA2_OFFSET`）非严格几何反演，FK 残差 ~1 mm 级别；1 cm 容差留余
量覆盖 caller 浮点漂移。**严格几何精度**目标超出 round 2 范围（如
未来真硬件回归发现末端 ~5 mm 偏差，走独立 spec/Plan 拍板改 path B
URDF + Pinocchio / Placo 闭环优化）。

指标说明与统计范围

CPU 百分比以整机全部逻辑核为 100%；占用核数是采样间隔内的平均 CPU 用量。例如占用 0.6 / 共 6 核，相当于整机 10%。

服务内存使用 cgroup 计费，包含进程内存、共享内存和文件缓存等。“其中共享内存”已包含在内存数值中，不能再次相加；下方整机内存用于对照，两者口径不同。

进程数包含服务的子进程，例如相机采集辅助进程；线程数包含这些进程的全部 OS 线程。服务职责由各行说明；有无进程不代表服务健康或硬件状态，无进程的服务仍按实际占用展示。

上下文切换率是各线程自愿与非自愿切换计数的增量，除以实际采样间隔；当前仅展示合计。睡眠、等待或调度让出 CPU 都会产生切换，次数不等于 CPU 利用率，也不直接表示故障。速率需要相邻且可比较的采样；初次采样或进程、线程发生变化时，相关项显示“采样中”；“—”表示对应指标不可用。

统计范围是 system.slice 下的 robot-*.service，后续纳入的 S1 等服务会自动列出。手动启动且未归属这些服务的进程不计入；服务级网络未单独采集，共享网卡流量不能准确归因到某一服务。

校准操作说明

网页模型与实物角度有偏差时，先用「对齐网页模型」。如果还需要重设电机零位或行程，先校准电机，再对齐模型。

对齐网页模型

  1. 连接状态流，在模型或关节列表中选中目标关节，展开「对齐网页模型」。手动摆姿态前先支撑机械臂并断扭。
  2. 以该关节的模型零位和正方向为准，摆两个明显不同的姿态。每次停稳后输入实物角度（度），记录姿态。夹爪先记录闭合，再记录张开。
  3. 摆第三个姿态（夹爪取中间开度），输入实测角度，点「记录复核姿态」。看清模型与实物的角差后再保存。保存只影响网页显示，可以点「恢复本关节默认显示」撤回。

校准单个电机

  1. 在模型或列表选中一个位置关节。支撑机械臂，在「关节」页确认该侧已断扭且急停锁存。回到「可视化 → 校准单个电机」点击「开启所选电机校准」，确认现场条件，等页面显示该电机已就绪。
  2. 手动把关节摆到参考中位并停稳，点击「标零（写入电机）」。这一步就会写入 EEPROM，把当前位置标为约 2047 raw，并临时放开旧限位。
  3. 手动摆到一个实际端点，停稳后点击记录；再摆到另一个端点并记录。最大、最小可以任一端先。页面按实测编码器值给出最小和最大 raw，核对后点击「写入限位并保存」。
  4. 如果手动运动跨过编码器 0/4095 边界，按页面提示恢复原校准，重新选中位。回执中断时先点「读取维护状态」；结束后核对该侧归还保护待机的结果。
